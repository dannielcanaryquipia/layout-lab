LAYOUT LAB - WIREFRAME SIMULATOR
INTAPPS BAC 1003 - Final Project (Pili & Pearl sample)

WHAT IT IS
A drag-and-drop tool for planning each slide of the pitch deck as a wireframe
before building it in Google Slides or Canva.
- 10 pitch slides plus a free slide, each with 5 templates (55 in all),
  including layouts A and B from the Pili & Pearl sample deck.
- Random layout: makes a new layout for the slide every time, from classic
  patterns (split, bento, columns, bands, sidebar, centered, full photo).
  It is not AI. Students choose, change and own the design.
- 17 block types: title, text, list, big number, button, photo, cutout PNG,
  logo, icon, video, audio, chart, table, steps diagram, card, color band.
  Every block has a "what goes here" tip.
- Design checks for each slide: must-have items, one focal point, not
  crowded, room to breathe, edges line up, no overlapping words, cutout
  breaking a card edge.
- Colors preview: try the Pili & Pearl palette or your own 5 colors, with
  live contrast numbers.
- Storyboard of all slides (prints landscape, one slide per page with its
  block labels; save as PDF), PNG download of a slide,
  Copy plan (block list with columns and rows), Save file / Open file.

HOW TO OPEN
1. Unzip the folder.
2. Double-click index.html (Chrome, Edge or Firefox). It works offline.
3. Work saves in the browser by itself. Use Save file to keep a copy or to
   move it to another computer, then Open file there.

HOW TO USE (for students)
1. Pick a slide at the top.
2. Try the templates, or press Random layout until one gives you an idea.
3. Drag blocks to move them; drag the blue dot to resize. Everything snaps
   to the 12-column grid. On a phone, use the buttons in Edit block.
4. Add blocks from the left panel: drag them in, or tap to add.
   To remove a block: click the red x on the selected block, press Delete,
   or use the button in Edit block. Ctrl+Z brings it back.
5. Rename each block with what you will really put there.
6. Make the design checks green. Type "(dark)" or "(accent)" in a card label
   to color that card.
7. Download a PNG or Copy plan for your design brief, then rebuild it in
   Google Slides (View > Guides) or Canva.

KEYS
Arrows move - Shift+Arrows resize - Ctrl+D duplicate - Delete removes -
] and [ change layers - Ctrl+Z / Ctrl+Y undo and redo - R random - M mirror -
G grid on or off

LINKS
index.html#menu opens the Menu slide directly (also #cover, #about, #need,
#numbers, #how, #customers, #offer, #contact, #sources, #free).

PUTTING IT ON MOODLE
Upload the zip to a File resource, unzip it inside Moodle, and set
index.html as the main file. Keep the css, js and assets folders next to it.

FOLDERS

css/app.css      layout and the wireframe styles
js/data.js       block types, slide rules and the 55 templates
js/gen.js        the random layout generator
js/app.js        drag and drop, checks, colors, storyboard, export
assets/fonts     Fraunces and DM Sans (SIL Open Font License, files included)
